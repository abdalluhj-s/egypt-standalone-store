# متجر Egypt Wear - منصة التجارة الإلكترونية المستقلة للسوق المصري

منصة تجارة إلكترونية مستقلة وسريعة للغاية، مبنية بأحدث تقنيات الويب: **Next.js 14 (App Router)**، **Supabase (PostgreSQL + Auth + Storage)**، ومهيأة للتشغيل عبر حافة الشبكة **Cloudflare Pages**.

---

## 🌟 أبرز مميزات المشروع

- **تجربة شراء مصرية سريعة (Zero-Lag Egyptian Checkout):**
  - شراء فوري كـ Guest بدون إجبار العميل على التسجيل.
  - دعم جميع المحافظات المصرية الـ 27 مع احتساب فوري لرسوم الشحن.
  - التحقق التلقائي من صحة أرقام الموبايل المصرية (`01xxxxxxxxx`).
  - تحويل فوري لرسالة الطلب المنسقة إلى واتساب لتأكيد الشحن الفوري.

- **محرك دفع إنستاباي الذكي (InstaPay Smart UX):**
  - نسخ عنوان الدفع اللحظي (IPA) بنقرة زر مع إشعار بصري.
  - توليد رمز QR ديناميكي لمسحه مباشرة من تطبيق إنستاباي.
  - رفع ومعاينة صورة إيصال التحويل (Screenshot) وحفظها بأمان.

- **حاسبة المقاسات الذكية (Interactive Size Recommender):**
  - خوارزمية ذكية لاقتراح المقاس المثالي (S, M, L, XL, 2XL) بناءً على الطول والوزن وتفضيل اللبس لتقليل نسبة المرتجعات.

- **مؤشر نفاذ المخزون الحي (Live Scarcity Badge):**
  - شارة تفاعلية تنبه العميل بالكمية المتبقية لزيادة معدل التحويل (FOMO).

- **تتبع مسار الشحنة بالرقم أو الهاتف (`/track`):**
  - صفحة خدمة ذاتية لمعرفة حالة الطلب في كل مرحلة (تم الاستلام ➔ تم التجهيز ➔ مع المندوب).

- **لوحة تحكم وإدارة معزولة بالكامل (`/admin`):**
  - حماية مسارات الإدارة على مستوى Edge.
  - إدارة كاملة للمنتجات والمخزون ورفع الصور لـ Supabase Storage.
  - إدارة الطلبات الواردة وتحديث مراحل الشحن وفحص إيصالات إنستاباي.

- **تطبيق ويب تقدمي (PWA):**
  - قابل للتثبيت على الهواتف كأبلكيشن مباشر خفيف بدون الحاجة لمتجر تطبيقات.

## 🚀 التشغيل المحلي (Local Development)

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev
```

افتح المتصفح على: `http://localhost:3000`

---

## 🗄️ إعداد قاعدة البيانات (Supabase SQL)

1. أنشئ مشروعاً جديداً على [Supabase](https://supabase.com).
2. افتح قائمة **SQL Editor** في لوحة تحكم Supabase.
3. انسخ محتوى الملف `supabase_schema.sql` بالكامل والصقه، ثم اضغط **Run**.
4. انسخ مفاتيح الـ API وضعها في ملف `.env.local`:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `SUPABASE_SERVICE_ROLE_KEY`

---

## ☁️ النشر على Cloudflare Pages

المشروع مهيأ بالكامل للنشر على Cloudflare Pages Edge Runtime عبر:
```bash
npm run pages:build
```
أو عن طريق ربط مستودع GitHub مباشرة بـ Cloudflare Pages.
